⚛️ SOCXIMA QUANTUM CORE

Sistema Cuántico de Alta Rendimiento

Bienvenido al Quantum Core

Socxima Quantum Core es un simulador de estados cuánticos de alto rendimiento con visualización 3D de esferas de Bloch, seguimiento de telemetría satelital en tiempo real y análisis relativista avanzado.

Estado: Sistema activo y funcional

📂 Ver en GitHub

🚀 Características Principales

⚛️ Simulador Cuántico

Motor de simulación de estados cuánticos con precisión de múltiples qubits. Cálculos de operadores y transformaciones unitarias en tiempo real.

🌐 Esfera de Bloch 3D

Visualización interactiva en Three.js de estados cuánticos en la esfera de Bloch con rotaciones y proyecciones en tiempo real.

🛰️ Telemetría Satelital

Seguimiento y análisis de datos de satélites con cálculos de órbitas y posiciones en tiempo real.

⚡ Análisis Relativista

Comparación de relatividad especial (RE) y general (RG) con correcciones gravitacionales y de velocidad.

🎛️ Composición de Circuitos

Constructor visual de circuitos cuánticos con puertas lógicas, mediciones y análisis de amplitudes.

📊 Análisis Estadístico

Herramientas para análisis de distribuciones de probabilidad y comportamiento cuántico.

🚀 Cómo Empezar

Instalación

git clone https://github.com/eveliollo/Cuantico.git
cd Cuantico
npm install
npm run dev

Compilación para producción

npm run build
npm run preview

Características disponibles

  • Simulación de estados cuánticos de 1-3 qubits
  • Visualización 3D interactiva de la esfera de Bloch
  • Composición y análisis de circuitos cuánticos
  • Cálculos relativistas (RE/RG)
  • Datos de telemetría satelital en tiempo real
